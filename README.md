# :moneybag: Personal Expense Tracker (Web)

**Personal Expense Tracker** is a sleek, modern web application designed to help you manage your personal finances with ease. Featuring a premium glassmorphic interface and real-time data visualization, it makes tracking your daily expenses and income both efficient and visually satisfying.

![Personal Expense Tracker Logo](https://raw.githubusercontent.com/anshulr229/Personal-Expense-Tracker/main/app-icon.png)

## :sparkles: Features

- :gem: **Premium Glassmorphic UI**: Beautifully designed interface with smooth animations and dynamic background effects.
- :chart_with_upwards_trend: **Financial Overview**: Real-time doughnut charts powered by **Chart.js** to visualize your income vs. expense ratio.
- :1234: **Integrated Calculator**: A built-in quick calculator that allows you to compute amounts and paste them directly into the transaction form.
- :date: **Monthly History**: Easily filter your transaction history by month to analyze your spending habits over time.
- :floppy_disk: **Local Persistence**: All your data is saved securely in your browser's local storage. No cloud required, ensuring complete privacy.
- :globe_with_meridians: **Web-Ready**: Accessible through any modern web browser without additional software.

## :hammer_and_wrench: Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Properties, Flexbox, Grid)
- **Logic**: Vanilla JavaScript (ES6+)
- **Charts**: Chart.js
- **Icons**: Font Awesome 6
- **Typography**: Google Fonts (Outfit)

## :rocket: Getting Started

No installation required! To run this project locally:

1. Clone or download the repository.
2. Open index.html in any modern web browser (Chrome, Firefox, Edge, etc.).

Alternatively, you can deploy this directory to **GitHub Pages**, **Vercel**, or **Netlify** for online access.

## :desktop: Screen Layout

- **Left Column**: View your current balance and add new transactions.
- **Center Column**: Visualize your data with the Financial Overview chart and view your transaction history.
- **Right Column**: Access the Quick Calculator for immediate computations.
